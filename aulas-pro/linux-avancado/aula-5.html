📚 Conteúdo

No Linux Mint, o APT é uma ferramenta importante para gerenciamento de pacotes.

Atualize os índices:

sudo apt update

Atualize pacotes:

sudo apt upgrade

Pesquise:

apt search NOME

Instale:

sudo apt install NOME

Remova:

sudo apt remove NOME

Sempre confira o pacote antes de instalar ou remover.

🧪 Desafio prático

Execute:

apt --version

Depois:

apt search htop

Pesquise também outro programa conhecido.
