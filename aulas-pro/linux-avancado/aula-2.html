Gerenciamento de Serviços

Aprenda a controlar serviços do Linux e entender o que inicia junto com o sistema.

📚 Conteúdo

Os serviços são programas que funcionam em segundo plano. O systemd é o sistema responsável por gerenciar muitos deles no Linux.

Para verificar o estado de um serviço:

systemctl status nome-do-servico

Para listar serviços em execução:

systemctl --type=service --state=running

Para iniciar um serviço:

sudo systemctl start nome-do-servico

Para parar:

sudo systemctl stop nome-do-servico

Para verificar se inicia automaticamente:

systemctl is-enabled nome-do-servico

⚠️ Evite desativar serviços sem saber para que servem.

🧪 Desafio prático

Execute:

systemctl --type=service --state=running

Escolha um serviço que você reconheça e consulte:

systemctl status nome-do-servico

Observe o estado, PID e mensagens exibidas.
