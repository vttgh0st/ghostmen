📚 Conteúdo

O Linux foi projetado para trabalhar com vários usuários.

Para descobrir seu usuário:

whoami

Para obter informações da conta:

id

Para descobrir seus grupos:

groups

Cada usuário possui um UID e cada grupo possui um GID.

Grupos ajudam a organizar permissões de acesso.

🧪 Desafio prático

Execute:

whoami
id
groups

Identifique seu usuário, UID e grupos.
