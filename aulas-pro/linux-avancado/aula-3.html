Permissões de Arquivos

Entenda leitura, escrita e execução e aprenda a trabalhar com permissões.

📚 Conteúdo

No Linux, arquivos possuem permissões para proprietário, grupo e outros usuários.

As três permissões principais são:

r = leitura
w = escrita
x = execução

Para visualizar permissões:

ls -l

Um resultado como:

-rwxr-xr--

pode ser dividido em proprietário, grupo e outros.

O comando chmod altera permissões.

Exemplo:

chmod +x script.sh

Isso adiciona permissão de execução ao arquivo.

Para estudar permissões numéricas:

4 = leitura
2 = escrita
1 = execução

Por exemplo:

chmod 755 script.sh

significa leitura/escrita/execução para o proprietário e leitura/execução para os demais.

🧪 Desafio prático

Crie um arquivo de teste:

touch teste.txt

Depois execute:

ls -l teste.txt

Adicione permissão de execução:

chmod +x teste.txt

Execute novamente:

ls -l teste.txt

Compare as permissões.
