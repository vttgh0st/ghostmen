Diagnóstico do Sistema

Aprenda a coletar informações básicas para descobrir o que está acontecendo no computador.

📚 Conteúdo

Diagnosticar um computador significa observar informações antes de tentar corrigir um problema.

Para saber há quanto tempo o sistema está ligado:

uptime

Para visualizar memória:

free -h

Para informações do processador:

lscpu

Para informações do kernel:

uname -a

Para visualizar processos:

ps aux

Uma boa análise normalmente começa observando CPU, RAM, armazenamento, processos e mensagens do sistema.

🧪 Desafio prático

Faça um pequeno diagnóstico executando:

uptime
free -h
lscpu
df -h
ps aux --sort=-%cpu | head

Anote quais recursos parecem estar sendo mais utilizados.
