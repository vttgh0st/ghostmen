Processos no Linux

Nesta aula você vai aprender o que são processos, como descobrir quais programas estão consumindo recursos e como monitorar o sistema pelo terminal.

🧠 O que é um processo?

Um processo é basicamente um programa que está sendo executado pelo sistema operacional.

Quando você abre o Chrome, por exemplo, o Linux cria processos para executar o navegador e suas diferentes tarefas.

Cada processo possui um identificador chamado PID.

⚡ Ver processos

Um dos comandos mais conhecidos é:

ps aux

Ele mostra processos em execução, usuário responsável, uso de CPU, uso de memória e outras informações.

🔥 Monitoramento em tempo real

Para acompanhar os processos em tempo real:

top

Outra ferramenta muito conhecida é:

htop

O htop apresenta uma interface mais amigável para visualizar CPU, memória e processos.

🔎 Encontrando um processo

Você pode procurar um programa específico usando:

ps aux | grep chrome

O símbolo | envia a saída de um comando para outro. Isso é chamado de pipe.

🧪 Desafio

Abra o terminal e execute:

top

Observe durante alguns segundos quais processos estão usando mais CPU e memória. Depois pressione:

q

para sair.
